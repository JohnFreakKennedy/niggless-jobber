% HOW TAILORING WORKS (keep these building blocks, the editor relies on them):
%   - \newcommand{\jobtitle}{...} is set to the job opening title per job.
%   - The text between "% @summary-begin" and "% @summary-end" is rewritten
%     to target the job. Keep the phrase "N years of experience": the number
%     is computed from personal_info.json work_history.
%   - Every \resumeItem{...} bullet may be reworded and reordered within its
%     role. Facts are never added: edits that introduce a technology or a
%     number that is not already in your CV are discarded automatically.
%   - Every \skillline{Category}{a, b, c} is reordered so the skills the job
%     asks for come first. Items are never added or removed.
%   - Write the full CV you would be happy to send; tailoring only re-weights
%     it. Keep it to one page: the PDF step tightens spacing if it overflows.
% =============================================================================
